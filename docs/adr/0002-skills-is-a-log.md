# Skills is a log, never in progress

The `skills` section never moves. It is a cumulative session log, not a live roster: a row is added on a skill's first invocation, one per name and source, a repeat changes nothing, and no row ever leaves. Every row means "this was invoked at some point in this session", so it has no present tense for motion to attach to, and animating a skill running now would make one mark carry both "was used" and "is working". The section carries no caveat either: it never claimed to show what is working.

This holds whatever the engine reports. Claude Code names no skill for a running tool call (`no-skill-for-a-call` in `MEMORY.md`), which invites reading the stillness as a gap that attribution would close. It is not a gap: a log has no now, and attribution arriving would not change that.
